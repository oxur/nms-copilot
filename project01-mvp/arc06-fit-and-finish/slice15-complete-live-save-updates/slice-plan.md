Refactor the existing producer into one shared private engine, with a private complete source snapshot holding existing SaveSnapshot plus the complete `save.to_core_player_state()` and `save.version` obtained from exactly the SAME SaveRoot parse. No initial event; unchanged reparse emits nothing. Legacy stream emits only existing nonempty SaveDelta, even for state-only/version-only input. Failed/unstable parses do not advance baseline, emit an event or mutate consumer state. Preserve selected-save canonical event filtering, atomic replacement, configured debounce, stability check and warning exactly at five consecutive parse failures; success resets counter.
4. Use one private producer/lifetime implementation for both adapters, preserving old public signatures and receiver types. Retain the debouncer and JoinHandle; shutdown flag plus notify recv_timeout(100ms) makes idle worker stoppable. Create worker with thread::Builder::spawn; map startup I/O failure to existing WatchError::NotifyError with worker-start context, without adding public variants. Drop stops debouncer, sets cancellation and joins; no detached parse worker, no panic on recoverable input, worker panic warning goes stderr without panicking Drop. Do not promise a hard deadline for arbitrary I/O/parser runtime.
5. New full stream uses sync_channel capacity1. Worker keeps at most one pending parsed update while trying to enqueue it; try_send retries with 10ms waits and shutdown/disconnected checks, without dropping/reordering updates during normal lifetime. Notify backend's existing internal event queue is not claimed bounded. Advance source baseline only after successful send or a successfully parsed unchanged event. Shutdown may discard an unsent pending update; already queued updates can be read before disconnect. Legacy delta queue remains unbounded for compatibility. No model/cache lock occurs in this producer.
6. Add `GalaxyModel::apply_save_update(&SaveUpdate)`; preserve `apply_delta`. Capture prior physical reality and selected view, apply existing atlas delta logic, then replace full PlayerState from the event. Final selection changes only when prior physical state exists and its reality differs from incoming current_address.reality_index; otherwise retain previous selected view, including absent prior physical state. Full PlayerState is authoritative over a contradictory synthetic delta movement for physical state/selection. Version stays in the event for the later writer; no GalaxyModel/archive field added. Imported systems/planets/bases are retained by existing additive delta rules; no wholesale rebuild, removals, placeholder inference/promotion or ensure_player_system change.
