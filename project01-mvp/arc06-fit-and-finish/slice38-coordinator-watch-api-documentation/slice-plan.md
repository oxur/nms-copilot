- `start` returns Watch(payload) for missingpath/initialparse/nativewatchsetup and Worker(io::Error) for coordinator-thread creation. WatchError itself has SaveNotFound(PathBuf)/NotifyError(String)/ParseError(String). CoordinatorStartError Display exact prefixes; std::error::Error::source returns NONE even for IO-backed Worker, because manual impl has no source override. Payload accessible by matching. Release guard BEFORE serialized disk writer; then publish event even on best-effort cache error. `None` bypasses extraction/write; Some is not prevalidated and only attempts on later accepted observations. Cache error stderr, no observer error/result or rollback; later updates continue. No session mutation by coordinator.
- AppliedSaveUpdate carries SaveUpdate(delta/full supported player/version), names_changed, preformatted notes. It does NOT carry DiscoveryNames map/full atlas/per-event query snapshot/cache success. Event can reflect name-only change even delta/notes empty; later reads see current model. Public fields can be constructed independently; struct itself validates nothing or applies nothing.
- subscribe unbounded receiver: events published after registration/no snapshot/replay; in-flight apply/write may publish to new subscriber. Perworker order, no slow-consumer wait/backpressure bound, clone/storage costs and memory not bounded; disconnected subscribers removed when publish next runs. Draining responsibility caller. Source error/worker panic not sent as an event.
- Drop signals shutdown/joinworker; worker drops/joins watcher; in-flight apply/write/publication completes before return, queued work not guaranteed flush. No fixed parser/disk/join deadline; release ALL model guards before Drop.
